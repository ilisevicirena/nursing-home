# Screenshots — shot list

Drop the images below into this folder using **exactly these file names** so the root
`README.md` picks them up automatically. Aim for a 1280–1440px wide browser window,
light theme, and seeded demo data (no real names).

| File name | What to capture | Notes |
|---|---|---|
| `demo.gif` | 8–15 s click-through: login → dashboard → open a resident → medical profile → an invoice | The hero animation. Keep it short and smooth. |
| `dashboard.png` | The main dashboard with charts / metrics / quick actions | This is the first still image recruiters see. |
| `residents.png` | The resident directory (grid/list) | Use fake names. |
| `medical-profile.png` | A resident's medical profile — medications + allergies | Shows clinical depth. |
| `calculation.png` | A billing calculation / invoice with line items | Shows the billing engine. |
| `calendar.png` | The calendar with a few events / a doctor-visit tour | Shows scheduling. |

## How to record the GIF (free tools)

- **Windows built-in:** Xbox Game Bar (`Win + G`) records the screen to MP4, then convert
  to GIF, **or** just embed the MP4 (GitHub plays short MP4s inline if you drag-drop them
  into a README on the web — but a committed `.gif` is the most reliable).
- **ScreenToGif** (free, open source) — records directly to optimised GIF, lets you trim
  frames. Recommended.

## Tips
- Blur or fake any data that could look like real personal info.
- Keep each PNG under ~500 KB (use PNG optimisation or export at reasonable quality) so the
  repo stays light and the README loads fast.
- Consistent window size across shots looks far more professional.
